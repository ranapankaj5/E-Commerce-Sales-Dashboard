# E-Commerce Sales Dashboard

## 📊 Project Overview

This project is an interactive E-Commerce Sales Dashboard developed using Microsoft Power BI.

The dashboard analyzes e-commerce sales performance using order and sales-detail data and provides business insights through interactive KPIs, charts, filters, and trend analysis.

## 🎯 Business Objectives

- Monitor overall sales performance
- Analyze revenue and profit
- Track order and quantity performance
- Identify top-performing products
- Analyze sales by category and sub-category
- Compare regional sales performance
- Identify sales trends over time
- Support data-driven business decisions

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- CSV
- Data Modeling
- Data Visualization
- Business Intelligence

## 📂 Dataset

The dashboard is built using two source files:

### Orders.csv

Contains order-level information used for analyzing customer orders, dates, locations and sales performance.

### Details.csv

Contains detailed sales information used for product, quantity, sales and profit analysis.

## 📈 Dashboard Analysis

The dashboard provides insights into:

- Sales Performance
- Revenue Analysis
- Profitability
- Order Analysis
- Product Performance
- Category Performance
- Regional Performance
- Sales Trends

## 🎛️ Interactive Features

The Power BI dashboard includes interactive filters and visualizations that allow users to analyze the data from different business perspectives.

Users can filter the dashboard and dynamically analyze sales performance across different dimensions.
